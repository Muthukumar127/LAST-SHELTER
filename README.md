# LAST SHELTER
npm install && npm start  → open http://localhost:3000 (same Wi-Fi: http://<PC-IP>:3000 on Android).
Test: open 2–4 tabs, one creates a room, others join with the 6-char code, host presses Start.
Controls: WASD, drag mouse (camera), Shift run, Space jump, E/F use. Mobile: joystick + buttons.
